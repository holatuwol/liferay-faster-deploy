Liferay Security Vulnerabilities By Release

Lists the published Liferay security vulnerabilities (LSVs). Check one or more Liferay DXP releases in the sidebar to list only the vulnerabilities that affect them, with a status column for each release showing whether it is affected and which releases fix it. Each LSV is followed by the LPE tickets that fix it (the one LPE ticket that resolved it, where that is known, and otherwise every LPE ticket linked to it). Checking several releases lets you compare them, such as the release you run now and the release you plan to upgrade to.

Warning: This is NOT an official Liferay tool, nor is it supported by Liferay in any way. Most affected releases are imputed from affects versions and fix versions recorded on the issues linked to each LSV, because Liferay does not provide exhaustive affected versions lists in its ticket metadata. The published security advisories remain the authoritative source of official documentation.

To check specific vulnerabilities, enter one or more CVE or LSV identifiers in the identifier filter. Matching vulnerabilities are listed even if they do not affect the checked releases, and each status is highlighted in green when that release is not affected, along with the reason. To search by text instead, enter one or more phrases in the text filter below it, one per line (such as nginx), each listing the vulnerabilities that affect the checked releases and have that text in their identifier, title, or details. Both filters can be used together, listing the vulnerabilities that match either one, and any identifier or phrase that matches no vulnerability (or, for a phrase, none that affect the checked releases) is listed below the filters.

If a customer has installed a hotfix, paste its tokens (the tickets it includes, such as LPD-12345 or LPE-12345) into the Hotfix Tickets field in the sidebar. Development tickets (LPD, LPS, LPSA, COMMERCE) are mapped to the LPE tickets they are linked to. A vulnerability is treated as fixed in a checked release if the hotfix includes every one of its LPE tickets that is not yet fixed in that release (or, for a few vulnerabilities, one LPE ticket that fixes it on its own), and it stays listed with a status explaining which hotfix tickets fixed it.

To narrow the list further, check one or more severities, classifications, or categories in the sidebar. A vulnerability is listed only if it matches one of the checked values in each group you use (leaving a group unchecked does not filter by it), and it matches a category if any of its categories is checked. Vulnerabilities that have not been published to customers yet are marked as Unpublished in the Published column, and they are hidden unless you uncheck Hide unpublished in the sidebar.

Click the LSV, Severity, Classification, or Published header to sort by that column (newest, most severe, or alphabetically first), or a release's Status header to list the vulnerabilities that are not fixed in that release line first, then those fixed in a later release, then those that do not affect it. Click the same header again to reverse the order.
