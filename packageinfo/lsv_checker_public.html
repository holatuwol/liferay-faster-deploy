Liferay Security Vulnerabilities By Release

Lists the published Liferay security vulnerabilities (LSVs). Check one or more Liferay DXP releases in the sidebar to list only the vulnerabilities that affect them, with a status column for each release showing whether it is affected and which releases fix it. Checking several releases lets you compare them, such as the release you run now and the release you plan to upgrade to.

Warning: This is NOT an official Liferay tool, nor is it supported by Liferay in any way. The affected releases are computed from fix versions recorded on the issues linked to each LSV, and the published security advisories remain the authoritative source.

To check specific vulnerabilities, enter one or more CVE or LSV identifiers in the filter. Matching vulnerabilities are listed even if they do not affect the checked releases, and each status is highlighted in green when that release is not affected, along with the reason.

To narrow the list further, check one or more severities, classifications, or categories in the sidebar. A vulnerability is listed only if it matches one of the checked values in each group you use (leaving a group unchecked does not filter by it), and it matches a category if any of its categories is checked.

Click the LSV, Severity, Classification, or Published header to sort by that column (newest, most severe, or alphabetically first), or a release's Status header to list the vulnerabilities that are not fixed in that release line first, then those fixed in a later release, then those that do not affect it. Click the same header again to reverse the order.
